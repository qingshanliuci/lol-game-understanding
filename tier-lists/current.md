# 当前版本认知总榜

快照：**2026-08-13 赛后**

这里同时维护两套榜：

1. **阵容原型层级**：这套结构在什么对局里是 T0、T0.5 或 T1；
2. **英雄位置层级**：LCK、LPL 分开，对五个位置逐路检验。

> 层级是当前窗口的工作判断，不是永恒强度。`T0.5` 表示接近最高档，但比 T0 多一个明确条件或少一项容错；`Counter T0` 表示后手价值能到 T0，不能偷换成盲选 T0。

## 一、阵容原型层级

- 详细榜单与 Counter 链：[当前阵容原型分级](../composition-tiers/current.md)

| 层级 | 阵容原型 | 一句话判断 |
|---|---|---|
| **T0** | 多点强开 + 第二轮输出 | 至少两个可达启动点，且第一人进场后仍有人承伤、跟控和持续输出。 |
| **Counter T0** | 完整反开保排 | 对冲阵是当前最明确的结构 Counter；没有明确冲阵对象时按 T0.5 读。 |
| **T0.5** | 前后排持续 + 反开锚点 | 正面下限高、逆风可守，但必须保住后排，不能只有一个会挨打的前排。 |
| **T0.5** | 边线牵制 + 跨图接应 | 对固定双核/五人抱团是强 Counter；落后时仍可改写比赛形式，但不是盲选模板。 |
| **T1** | 抓单接力 | 对分散阵型有效；面对完整五人强开时容易被迫正面接团。 |
| **T1** | 长手消耗/阵地 | 只有拿到先入权、清线与反进场时才成立；“只有长手”是版本陷阱。 |
| **陷阱** | 单轮冲阵 / 无保护多核 | 理论伤害很高，但第一轮失败后无法重建阵型，逆风尤其脆弱。 |

## 三、逆风标签怎么读

| 标签 | 含义 | 代表英雄 |
|---|---|---|
| **逆风锚点** | 不吃经济也能维持阵容的一条关键链，让队伍仍有下一轮。 | 慎、波比、璐璐、萨勒芬妮、牛头、巴德 |
| **逆风输出** | 落后时仍较容易把伤害送到目标，而不是只在领先时压人。 | 伊泽瑞尔、蛇女、瑞兹、霞 |
| **逆风改图** | 不一定正面更强，但能用边线/全球技能迫使对手分兵。 | 约里克、梦魇、卡牌、慎 |
| **顺风放大器** | 领先时很强，落后后功能衰减快；不能误标成逆风英雄。 | 杰斯、卢锡安、烬、鳄鱼、女警 |

### 为什么慎要特别标记

慎不是“任何局都盲拿”的万能 T0；他的价值在于：

- 对手已经展示冲阵/抓单时，后手把一条边线和正面保护连起来；
- 大招给第一位被开的核心增加有效血量，允许队伍进入第二轮；
- 自己低经济仍保留嘲讽、护盾、跨图响应，因此特别适合作为 **Counter + 逆风锚点**；
- 当前窗口 LCK 辅助 `22局 15-7`，LPL 辅助 `28局 15-13`；赛区差异说明它不是脱离队伍执行的自动胜利按钮。

## 数据边界

- LCK：2026-07-29 至 08-13，59 小局；LPL：2026-07-22 至 08-13，108 小局。
- `BP presence` 按每局选用或禁用去重；Fearless 已消耗英雄不会记作后续 ban，因此仍会低估真实优先级。
- 层级同时使用 BP、战绩与机制检验；不会按胜率机械排序。
- 逆风战绩样本普遍很小，只能支持标签和复查顺序，不能直接当预测概率。
