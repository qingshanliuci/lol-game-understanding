# 术语表

| 术语 | 含义 |
|---|---|
| BP presence | 英雄被选或被 ban 的局数占比；Fearless 下会低估已被消耗英雄的后续价值。 |
| blind T0 | 早选仍较安全、难被常规 BP 稳定惩罚的最高档英雄。 |
| T0.5 | 接近最高档，但比 T0 多一个明确条件或少一项容错。 |
| Counter T0 | 只在明确后手对位或阵容条件下达到最高档价值，不能偷换成盲选 T0。 |
| 版本陷阱 | 表面顺位或功能很诱人，但隐含前置条件经常不被满足的选择。 |
| 逆风锚点 | 低经济仍能维持承伤、保护、反开、清线或改图链，让队伍保有第二轮的英雄。 |
| 顺风放大器 | 领先时能快速扩大优势、落后后职责衰减很快的英雄或组合。 |
| 第一接触 | 真正能让战斗开始并让队友跟上的动作，不等同于英雄拥有控制技能。 |
| 第二轮输出 | 第一套技能结束后仍能持续制造有效伤害或控制的能力。 |
| 保护链 | 通过治疗、护盾、净化、位移、反开或承伤让核心活过第一轮的组合。 |
| 经济断点 | 某位置必须在特定时间取得装备/等级，否则阵容路径明显变差的节点。 |
| candidate | 有可复盘机制的候选案例，尚未证明可稳定复现。 |
| validated | 核心机制有跨队伍、跨对手与反例支持，达到较高证据门槛。 |
