## 为什么这样分

### Counter T0：完整反开保排

当前最明确的结构 Counter。更新至 08-13 的原型对局中：

- 对强开冲阵：合计 `9-4`；
- LCK `4-2`；LPL `5-2`。

它不是“软辅越多越好”，而是完整交付链：

`让对手先交位移 → 第一核心活下来 → 第二层控制切断跟进 → 持续核打第二轮 → 转资源`

常见组件：慎、波比、蛇女、霞、璐璐、萨勒芬妮、牛头、巴德。慎之所以特殊，是它能把边线、第一轮救援和后续嘲讽连成一条链。

**降级条件：**没有值得保护的持续核心；所有保护技能只能保一个人；清线太差导致根本进不了资源区。

### T0：多点强开 + 第二轮输出

“强开冲阵”裸原型在两个赛区都接近五五开，所以不是只要三个突进就 T0。升级到 T0 必须满足：

1. 至少两个独立、可到达的启动点；
2. 第一位进场者能存活或被保护；
3. 后续有持续输出/范围控制，而不是全员把技能一次交完；
4. 赢第一轮后能拿塔、龙或男爵。

当前对抓单接力合计 `6-1`；对“只有长手”合计 `14-11`。GEN G2 的梦魇/安蓓萨/慎 + 蛇女/萨勒芬妮就是完整版本；TES G2 的鳄鱼/皇子则更接近单轮版本陷阱。

### T0.5：前后排持续 + 反开锚点

纯“前后排持续”与强开对局合计 `22-19`，没有足够优势直接封 T0。只有补上慎、波比、璐璐、萨勒芬妮、霞等反开锚点，后排能活过第一轮，才接近 T0。

**逆风价值：**真前排能用低经济买时间，持续核不依赖一次技能，保护位能让阵型重建。GEN G1 的奥拉夫/瑞兹/女警/巴德提供了这一类韧性。

### T0.5：边线牵制 + 跨图接应

这是 **Counter T0.5**，不是盲选 T0：

- LCK 主原型 4 次 3-1，其中落后至少500金后2胜3局；
- 对前后排持续的已观察对局合计3-1；
- 对长手阵地合计3-1。

约里克/奥拉夫/青钢影负责制造边线真威胁，梦魇/瑞兹/卡牌/慎负责跨图或快速接应。WBG G2 在 `-703@15` 后翻盘的关键不是正面更强，而是约里克先让 NIP 无法五人完整到场。

**降级条件：**边线点打不出单带压力；正面四人没有清线；跨图技能落地后仍没有持续输出。

### T1：抓单接力

需要视野和人员分散才能制造理想画面。面对完整五人强开时，当前对局仅 `1-6`。因此它是对局工具，不是版本通解。

**升到 T0.5 的条件：**抓到第一人后能立刻转大资源；有第二个全球/定点按钮；正面不因对手抱团就完全失去功能。

### T1：长手消耗/阵地

主原型当前 LCK `8-9`、LPL `12-20`，LPL 尤其低迷。问题不是伤害不够，而是：

- 后进入河道时射程优势无法展开；
- 没有反进场就会被直接缩短距离；
- 落后时边线和视野同时收缩，只剩理论清线。

只有满足“先入权 + 清线 + 反进场 + 至少一条不崩边线”才是合格 T1；缺任一项就属于“只有长手”的版本陷阱。

## 阵容 Counter 链

```text
完整反开保排  ──克制──> 多点强开/冲阵
多点强开      ──克制──> 只有长手、抓单接力
边线牵制      ──拆解──> 固定双核、标准五人前后排
长手阵地      ──条件克制──> 缺到达、缺侧翼的笨重短手
```

这不是闭环石头剪刀布。决定层级是否兑现的仍是：资源区先入权、经济落点、召唤师技能、选手熟练度和队伍执行。

## 每日阵容分级卡

每局 BP 锁定后先给两个结论：

1. **主原型层级**：T0 / T0.5 / T1 / 陷阱；
2. **当前对局修正**：`+0.5`（Counter 成立）/ `0` / `-0.5`（被克或职责缺失）。

示例：

- 完整反开保排 `T0`，对多点冲阵 Counter 成立：维持 `T0`；
- 边线牵制基础 `T0.5`，对固定双核且边线无解：对局可升 `T0`；
- 长手阵地基础 `T1`，但没有先入权和反进场：降为 `陷阱`；
- 多点强开表面 `T0`，但只有皇子一人承首轮、后排跟不上：降为 `T1/陷阱`。

## 数据边界

- 原型分类只是一套可审查压缩表示，不是 Riot 官方分类，也不是英雄因果系数。
- 对局样本仍小；`9-4` 等只支持 Counter 线索，不等于 69.2% 的未来胜率。
- LCK/LPL 的主原型战绩不能直接比较赛区强弱；队伍、红蓝方、Fearless 局序均有混杂。
- 当前分级是为了让每日复盘统一语言，进入预测系统前仍需市场消融和样本外验证。
