## 不应误读

- “落后 700 金翻盘”不代表阵容天然有 700 金容错；经济落点、龙塔、装备与召唤师技能同样重要。
- 完全相同的五人组合往往没有复现样本；验证应围绕机制原型，而不是只查 exact comp。
- 强队操作差距可能伪装成阵容韧性，必须保留失败反例和队伍强度对照。
